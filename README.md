# Clínica Escola

Sistema web de gestão interna desenvolvido por estudantes de **Análise e Desenvolvimento de Sistemas (ADS)** da **UNINASSAU**.

</div>

---

## Sobre o projeto

O **Clínica Escola** tem como propósito centralizar informações e otimizar processos administrativos e clínicos, oferecendo uma solução digital para apoiar a organização e o funcionamento de uma clínica-escola.
