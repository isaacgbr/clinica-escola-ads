# Clínica Escola

Sistema desenvolvido como projeto acadêmico para gerenciamento de uma Clínica Escola.

## Estrutura do projeto

- `backend/` — API e regras de negócio
- `frontend/` — interface da aplicação
- `database/` — recursos relacionados ao banco de dados
- `docs/` — documentação do projeto

## Equipe

Projeto desenvolvido em equipe por alunos do curso de Análise e Desenvolvimento de Sistemas.
